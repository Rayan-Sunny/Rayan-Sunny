# Rayan Hussain

**AI Engineer · Final-Year BSAI @ FAST-NUCES**  
Specializing in applied machine learning, computer vision, and low-latency edge AI systems.

---

### Expertise

* **Multimodal Computer Vision:** Experience implementing Vision Transformers (ViT) and autoregressive language decoders for cross-attention tasks such as vision-language image captioning.
* **Edge AI & TinyML:** Developing quantized neural networks for resource-constrained microcontrollers (ARM Cortex-M4F), running on-device inference with ultra-low latency and minimal RAM overhead.
* **Fullstack AI Systems:** Building end-to-end applications integrating PyTorch backends, high-performance FastAPI asynchronous REST services, and responsive React clients with Web APIs.

---

### Featured Projects

* **[Image Captioning Studio](https://github.com/Rayan-Sunny/image-captioning-studio)**  
  A vision-language web studio powered by Salesforce BLIP (ViT-B/16 + BERT text decoder) with real-time text-to-speech audio narration and iPhone HEIC photo support.  
  `PyTorch` · `Transformers` · `FastAPI` · `React 18`

* **[SmartBand AI](https://github.com/Rayan-Sunny/Smartband-ai)**  
  An embedded wrist-worn physical activity recognition and fall detection system running on the Arduino Nano 33 BLE Sense Rev2 with 1 ms on-device inference latency.  
  `Edge Impulse TinyML` · `C++` · `ArduinoBLE` · `PWA`

* **[Wuzzle](https://github.com/Rayan-Sunny/Wuzzle-)**  
  Wordle-inspired puzzle game featuring an intelligent AI solver engine that provides analytical strategic feedback on player moves.  
  `Python` · `Algorithms` · `Web`

* **[AI CLI Tool](https://github.com/Rayan-Sunny/ai-cli-tool)**  
  A developer productivity tool that translates plain natural language requests into executable terminal commands using LLM APIs.  
  `Python` · `CLI` · `LLMs`
